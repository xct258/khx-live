使用说明
📌 工具简介

本工具用于从括弧笑直播回放中选取片段、预览顺序并合并为一个成品视频。核心功能包括：

  • 时间轴切片：通过视频播放器+时间轴工具精确定位起点终点，支持帧精确切片。
  • 字幕切片：基于 srt/txt/vtt/ass 字幕文件快速选取时间段。
  • 跨视频合并：可从多个不同视频中分别选取片段，按自定义顺序合并。
  • 片段预览：服务端实时切片，100% 保证与最终成品一致（帧精确）。
  • 片段导入导出：支持导出为 JSON 备份，也支持从成品视频元数据中恢复。
  • 历史输出管理：记录所有合并成功的视频，支持下载、复制链接、删除。
  • B 站投稿：通过 biliup 工具一键上传到 B 站（含封面、标签、简介）。
🚀 推荐流程（新手速览）
  1. 选择视频：点击"选择视频"按钮，在弹出的目录树中浏览文件夹，点击视频文件确认选择。
  2. 选择切片方式：根据需要勾选"启用视频预览"（时间轴精确定位）和/或"使用字幕切片"（基于字幕快速选取）。
  3. 添加片段：
    • 时间轴方式：播放到需要的位置按 Q 设起点、W 设终点自动添加。
    • 字幕方式：在字幕列表中点击 + 将该字幕时间段加入列表。
    • 手动方式：在"片段工坊"直接输入时:分:秒格式的起止时间，点"确认添加片段"。
  4. 检查与调整：打开"待合并片段"，预览全部片段顺序，拖拽排序、删除不需要的片段。
  5. 提交合并：填写用户名（必填）和文件名（可选），选择"原版"或"压制版"源，点击"开始合并"。
🎬 视频选择与目录树
  • 打开方式：页面顶部"选择视频"按钮，或播放器控制栏右侧的"选择视频"按钮均可打开目录树弹窗。
  • 目录结构：目录树基于 /rec/videos/括弧笑bilibili/压制版/ 目录，按日期和直播场次组织。只展示包含预览版视频（文件名以 预览版- 开头）的目录。
  • 导航操作：点击文件夹展开下级（懒加载），顶部的"← 返回"按钮可回到上级目录。路径栏显示当前位置。
  • 选择确认：点击视频文件名即完成选择，弹窗自动关闭，播放器区域加载视频。
  • 源版本说明：合并时"原版"使用 括弧笑bilibili/原文件/ 目录中的无压制源文件；"压制版"使用 括弧笑bilibili/压制版/ 目录中的带弹幕压制文件。
📐 时间轴切片（视频预览模式）
  • 启用条件：勾选"启用视频预览"复选框，选择视频后点击预览区域中的"预览"按钮，等待视频加载完成。
  • 播放控制：播放/暂停（空格）、后退5秒、前进5秒按钮；进度条支持拖拽和点击跳转，悬停时显示时间戳工具提示。
  • 倍速播放：支持 0.5x、1.0x、1.25x、1.5x 倍速，通过播放器右上角下拉菜单切换。
  • 设置切片点：
    • 按 Q 键将当前位置设为起点（时间轴出现绿色标记和半透明区域）。
    • 按 W 键将当前位置设为终点（时间轴出现红色标记）。
    • 起点和终点同时存在时自动添加片段到列表；也支持先设完再按 C 或 Enter 手动添加。
  • 时间轴工具：
    • 缩放：支持全图显示和一倍/二倍/四倍视图缩放，方便精细调整。
    • 跟随播放：开启后时间轴自动随播放进度滚动。
    • 缩略图预览：时间轴上方显示缩略图（默认每 30 秒一张），帮助定位画面内容。
    • 音频波形：时间轴下方显示音频波形图，方便根据声音波形特征定位。
    • 片段显示：已添加的片段在时间轴上以彩色高亮条显示。点击片段可选中，按 Delete 键删除。
    • 预览选中片段：单击选中某已添加片段后按 P 键，服务端实时切片并以弹窗播放，效果与成品完全一致（帧精确）。
  • 手动添加：在"片段工坊"区域直接输入起点和终点时间（格式 HH:MM:SS 或 HH:MM:SS.mmm），点击"确认添加片段"。
📝 字幕切片模式
  • 启用条件：服务端自动在同目录的原文件目录下查找同名的 .srt / .txt / .vtt / .ass 字幕文件。找到后勾选"使用字幕切片"显示字幕列表。
  • 字幕列表：按时间顺序排列所有字幕条目，每条显示时间范围和文本内容。条目较多时分页显示，支持翻页和页码跳转。
  • 定位播放：点击任意字幕条目可跳转播放器到对应时间点；点击 ▶ 按钮可播放对应视频/音频片段。
  • 添加字幕片段：点击字幕条目上的 + 按钮，将该字幕的起止时间作为一个片段添加到待合并列表。已添加或重叠时会显示为可移除状态。
  • 字幕编辑：选中条目后点击"编辑"，可修改起止时间和文本。保存后写回原始字幕文件并自动备份（生成 _原始备份 后缀文件）。
  • 删除条目：编辑模式下点击"删除"从字幕文件中移除该条目。
  • 变更记录：每次保存后在字幕文件同目录下生成 _字幕变更记录.txt，记录操作时间、操作人、修改内容。
  • 撤回功能：保存后如有误，可点击"撤回"回退到上一个备份版本。
🔧 片段工坊
  • 当前视频信息：显示当前正在编辑的视频文件名，方便跨视频切片时区分。
  • 手动时间输入：在"起点"和"终点"输入框中输入时间值，格式 HH:MM:SS 或 HH:MM:SS.mmm（如 01:23:45 或 01:23:45.678）。
  • 确认添加：点击"确认添加片段"按钮，将当前输入的时间段作为一个片段加入待合并列表。
  • 待合并片段入口：点击"待合并片段 (N)"按钮（N 为当前片段总数），打开完整片段列表弹窗。
📋 片段列表管理
  • 弹窗布局：顶部显示标题和"清空"按钮（带二次确认），中部为片段列表，底部为操作按钮。
  • 片段卡片：每个片段显示序号、视频文件名、起止时间、时长。同一视频的片段用相同颜色区分。
  • 拖拽排序：拖动卡片右侧手柄调整顺序，最终合并按此顺序执行。正在切片/合并时拖拽被禁用。
  • 单个删除：点击片段卡片上的 × 按钮删除该片段。
  • 勾选删除：勾选多个片段左侧的复选框，点击"勾选删除"批量移除。
  • 全屏预览：点击"预览全部"按待合并顺序连续播放所有片段。当前播放的片段高亮显示。支持播放/暂停、进度条拖拽。
  • 自动保存：片段列表和用户名自动保存在浏览器 localStorage 中。刷新页面时会弹窗提示是否恢复。
📦 导入与导出
  • 导出为文件：点击"导出"按钮，将当前全部片段信息保存为 clips_日期时间.json 文件。适合备份或在不同设备间转移。
  • 从文件导入：点击"导入"→ 选择"从导出的文件导入"，选择之前导出的 .json 文件恢复片段列表。注意：导入会替换当前所有片段，如有现有片段会先弹窗确认。
  • 从成品视频元数据导入：点击"导入"→ 选择"从成品视频元数据导入"，粘贴成品视频的元数据 JSON。获取方式：ffprobe -v error -show_entries format_tags=comment -of default=noprint_wrappers=1:nokey=1 文件.mp4，或从 .meta.json 侧边文件复制。
⌨️ 快捷键大全
快捷键仅在视频预览已加载、且焦点不在输入框/按钮/文本区域上时生效。
◆ 切片操作
Q将当前位置设为起点。 W将当前位置设为终点。起点和终点都存在时自动添加片段。 C / Enter按当前起点和终点手动添加片段。 F跳转到起点位置。按住 Shift 则跳转后播放。 J跳转到终点位置。按住 Shift 则跳转后播放。
◆ 播放控制
Space播放 / 暂停切换。 ←后退 1 秒。 →前进 1 秒。
◆ 片段操作
P预览时间轴上当前选中的已添加片段。 D删除时间轴上选中的片段。按住 Shift 则保留起点标记。
🔨 合并任务
  • 前提条件：待合并片段中至少有一个片段；用户名不能为空。
  • 总时长限制：所有片段时长之和不得超过 90 分钟（5400 秒），提交时会校验。
  • 命名规则：输出文件格式为 用户名称-文件名称-时间戳.mp4，存放在 /rec/videos/切片成品/用户名称/ 下。"文件名称"可选填，留空默认为 merged。支持实时预览文件名。
  • 源版本选择：
    • 压制版：从 压制版 目录中选取有弹幕渲染的视频作为源。
    • 原版：从 原文件 目录中选取无压制视频作为源。
  • 任务队列：服务端同时只执行一个合并任务。新提交的任务自动进入队列排队。进度弹窗会显示当前任务进度和自己在队列中的位置。
  • 进度跟踪：
    • 切片阶段：逐个处理每个片段，显示"第 N/总 个片段"、片段内进度百分比、已处理时长/总时长、ffmpeg 实时速度/码率/帧率。
    • 合并阶段：将所有切片后的片段合并为一个文件，显示合并进度百分比。
    • 预计剩余时间：基于已处理速率估算剩余时间。
  • 取消任务：进度弹窗中的"取消当前任务"按钮可中断正在执行或排队的任务。取消后已生成的临时文件会自动清理。只能取消自己发起的任务（基于 token 校验）。
  • 完成处理：
    • 成功：弹窗显示"合并完成"，提供"下载"、"复制链接"按钮，询问是否清空当前片段列表。
    • 失败：显示错误信息（ffmpeg 日志尾部），可复制错误内容。
    • 取消：显示已取消，片段列表保留，可重新提交。
  • 元数据：成品视频会写入 comment 标签，包含所有片段来源信息（schema、视频名、起止帧号、源文件、帧率、精确时长等）。同时同目录下生成 .meta.json 侧边文件。
📺 历史输出与 B 站投稿
  • 历史记录：每次合并成功后自动存入浏览器 localStorage。点击"历史输出"查看所有记录，每条包含文件名、用户名、创建时间、文件大小。
  • 操作按钮：
    • 下载：直接下载成品视频文件。文件已被删除时按钮自动禁用。
    • 复制链接：复制可直接下载的 URL 到剪贴板。
    • 删除记录：从服务器删除成品文件并移除记录。
    • 投稿到 B 站：打开投稿弹窗。
  • 投稿弹窗字段：
    • 视频标题（必填）：B 站视频标题。
    • 视频简介（可选）：B 站视频简介。
    • 视频封面（可选）：上传封面图片（最大 5MB），选中后显示文件名，可移除重新选择。
    • 视频标签（必填，至少 1 个）：输入后按回车/空格/逗号添加，最多 10 个。点击标签上的 × 可移除。
  • 上传进度：投稿提交后弹窗显示实时进度（百分比、上传速度、剩余时间、日志输出）。支持"停止投稿"取消当前上传。
  • 投稿状态：上传完成后显示"成功"或"失败"及详细信息。服务重启时未完成的上传自动标记为中断。
  • 测试模式：当前服务运行在测试模式下，投稿不会真实上传，仅返回命令预览。
📊 辅助功能
  • 缩略图：时间轴上方自动加载视频关键帧缩略图（默认每 30 秒一张），方便通过画面内容定位。
  • 音频波形：时间轴下方自动生成音频波形图。基于原文件目录下的 .m4a 音频文件，通过 ffmpeg 提取峰值振幅生成。支持缩放联动。
  • 全屏模式：点击播放器右上角的 ⛶ 按钮进入全屏模式。
  • 站点统计：页面底部显示访问次数、合并成功次数、下载次数。
⚠️ 重要注意事项
  • 片段重叠限制：同一视频内的片段不能互相重叠（时间轴上有交叉检查），但相邻片段可以首尾相接。
  • 操作限制：正在切片、合并或排队时，片段添加、删除、排序等编辑操作会被禁用。
  • 网络要求：视频预览、缩略图和波形加载都需要从服务器拉取数据。网络较慢时建议关闭视频预览，仅使用字幕切片或手动输入时间。
  • 本地存储：自动保存、历史输出和"不再提示"选项均保存在当前浏览器的 localStorage 中。更换设备或清理浏览器数据后不会保留。
  • 元数据恢复：成品视频写入的切片元数据可通过"导入 → 从成品视频元数据导入"恢复片段列表，方便后续修改后重新合并。
  • 临时文件：切片过程中生成的临时文件位于服务端 clips_tmp/ 目录，合并完成后自动清理。服务重启时也自动清理残留临时文件。
  • 缓存清理：服务端定期自动清理：临时文件（6 小时）、封面上传（24 小时）、缩略图缓存（7 天）、波形缓存（14 天）。
  • 并发限制：合并任务和 B 站投稿任务各自同时只能运行一个，其余自动排队。投稿与合并互不干扰。
  • 安全机制：所有文件访问经过 sanitize 校验，防止路径遍历。任务取消需要验证 token。
  • 问题反馈：工具仍在持续迭代。如遇到异常，请保留错误提示、视频名称和操作步骤方便排查。
